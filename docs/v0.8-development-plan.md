# Resume Atelier v0.8 开发与验收计划

基线为独立插件 0.7.0（`d913331`）。目标是在同一份中英文 Markdown 上完成职位副本、纸面微调、结构排版与 Obsidian 桌面端原生 PDF 导出。最终验收使用虚构简历和独立测试库。

## 文档约定

- 正文按源顺序表达姓名、联系方式、二级栏目、三级经历及其段落和列表。工具栏与手写共用 `### 职位 · 公司 | 日期`，可读半角或全角分隔符。双链别名、链接、行内代码、转义和正文中的竖线保留原意。现存 HTML 经历块、自定义 CSS、表格、列表与嵌入继续通过 Obsidian 原生渲染。
- 主题 ID 继续使用 `resume_style`，几何参数和纸张归 `resume_layout`。每份稿件的栏目选择归 `resume_sections`。例如 `核心技能: { region: sidebar, display: tags }` 或 `荣誉: { hidden: true }`。字体、栏宽、头像裁切和时间轴线条归主题 CSS。插件 ID 沿用 `careeros-resume-layout`。
- 调整正文顺序会移动 Markdown 段落。分配栏位、隐藏栏目和换模板只修改版式属性。单栏按正文顺序显示，显隐属于职位副本，跨模板生效。通过标题引用栏目；重名、改名和失配在面板可见。Git 中可独立审阅每次正文修改。
- 工作台先将源行与渲染节点关联，再对本笔记的栏目与条目归组。阅读视图保留线性流，采用块内增强。原生打印按实际生命周期应用同一份规则。保护的母版和冻结稿通过副本进入编辑。

## 实施顺序与通过条件

| 步骤 | 交付 | 如何验收 |
| --- | --- | --- |
| 1. 修复四边拖动 | 纸面手柄使用当前预览的尺寸，保留边距锁、微调与撤销 | 在 0.7.0 发布包先复现，再让同一用例通过。四个方向分别在 100% 和缩放视图移动相同的实际毫米数，核对数值、相对边联动、释放后保存、取消后复原。运行构建及全量检查。 |
| 2. Markdown 经历头 | 工具栏新增与编辑默认写简写，双语示例使用简写。旧 HTML 单独识别 | 新建、修改日期、撤销、关闭后重新打开。粗体与链接仍可用；覆盖别名、行内代码、转义、全角竖线、普通三级标题和代码围栏。比对单条修改的 diff；旧 HTML 原样打开，自定义 HTML 可继续按源码编辑。 |
| 3. 定位与栏目属性 | 先按源顺序绑定块；栏目与条目各有范围。保存、试排、复制及并发编辑都尊重已有属性 | 用两个同名列表项和后置技能栏验证纸面点击、源码光标双向定位。调边距、撤销、复制后回读 YAML，核对纸张、栏目规则、扩展字段；版式 diff 只涉及 frontmatter。覆盖只读母版、过期编辑、重名和失配的栏目。 |
| 4. 一种双栏样式与职位显隐 | 用完整条目归组实现主栏和侧栏。在工作台分配栏位、恢复栏目，原生阅读按原顺序增强 | 源稿含普通段落、技能、嵌入和旧经历块。把后置技能放入侧栏，隐藏荣誉，点击正文再改一行；切回单栏后正文顺序正确，副本仍隐藏荣誉。检查旧主题直接子选择器、普通笔记试排和保护稿。 |
| 5. 原生 PDF 与多页纸张 | 预览、收紧、分页提示和原生打印共用 A4／US Letter 的实际尺寸 | 从工作台和笔记原生菜单导出。用两页中英文样例、手动分页和超过一页的经历核对页数、纸张、首末条、标题与后续正文、边距；查看渲染图片并提取文本与链接，确认隐藏项不在成品，长条目完整，复制顺序可读。核对导出后库级偏好复原。记录 Obsidian 版本和两个入口的差异。 |
| 6. 扩展五类常用结构 | 复用经历头、头部和栏目，补时间轴、头像比例、技能标签与快捷样式。保留作用域 CSS | 在同一篇 Markdown 上切换经典、双栏、时间轴；技能列表可显示为标签，头像可调比例，强调色及栏目／列表间距可还原。比对正文、主题作用域、跨页结果；切换及撤销均保留自定义样式和原文。 |
| 7. 候选版本整体验收 | 更新双语使用说明、示例和维护指南，核对安装包 | 在干净库安装三个发布文件，走完「母版 → 职位副本 → 放置技能 → 隐藏荣誉 → 点击纸面修改 → 两页 PDF」。再从 0.7.0 升级并重载，核对设置、旧主题、最近文件和已确认稿。构建可重复，`npm run check` 通过，实测和未验项目分别记录。 |
