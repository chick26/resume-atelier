# Resume Atelier v0.8 开发与验收计划

基线为独立插件 0.7.0（`d913331`）。目标是在同一份中英文 Markdown 上完成职位副本、纸面微调、结构排版与 Obsidian 桌面端原生 PDF 导出。最终验收使用虚构简历和独立测试库。

## 文档约定

- 正文按源顺序表达姓名、联系方式、二级栏目、三级经历及其段落和列表。工具栏与手写共用 `### 职位 · 公司 | 日期`，可读半角或全角分隔符。双链别名、链接、行内代码、转义和正文中的竖线保留原意。现存 HTML 经历块、自定义 CSS、表格、列表与嵌入继续通过 Obsidian 原生渲染。
- 主题 ID 继续使用 `resume_style`，几何参数和纸张归 `resume_layout`。每份稿件的栏目选择归 `resume_sections`。例如 `核心技能: { region: sidebar, display: tags }` 或 `荣誉: { hidden: true }`。字体、栏宽、头像裁切和时间轴线条归主题 CSS。插件 ID 沿用 `careeros-resume-layout`。
- 讨论中的 `resume_sidebar` 合并到每栏的 `region`，让一个栏目只有一处配置来源。工作台负责读写这些属性，手写 Markdown 的用户也可以直接查看或修改。显隐仅作用于成品展示，源稿和阅读视图可检查完整内容。
- 调整正文顺序会移动 Markdown 段落。分配栏位、隐藏栏目和换模板只修改版式属性。单栏按正文顺序显示，显隐属于职位副本，跨模板生效。通过标题引用栏目；重名、改名和失配在面板可见。Git 中可独立审阅每次正文修改。
- 工作台先将源行与渲染节点关联，再对本笔记的栏目与条目归组。阅读视图保留线性流，采用块内增强。原生打印按实际生命周期应用同一份规则。保护的母版和冻结稿通过副本进入编辑。

| 1. 修复四边拖动 | 纸面手柄使用当前预览的尺寸，保留边距锁、微调与撤销 | 在 0.7.0 发布包先复现，再让同一用例通过。四个方向分别在 100% 和缩放视图移动相同的实际毫米数，核对数值、相对边联动、释放后保存、取消后复原。运行构建及全量检查。 |
| 2. Markdown 经历头 | 工具栏新增与编辑默认写简写，双语示例使用简写。旧 HTML 单独识别 | 新建、修改日期、撤销、关闭后重新打开。粗体与链接仍可用；覆盖别名、行内代码、转义、全角竖线、普通三级标题和代码围栏。比对单条修改的 diff；旧 HTML 原样打开，自定义 HTML 可继续按源码编辑。 |
| 3. 定位与栏目属性 | 先按源顺序绑定块；栏目与条目各有范围。保存、试排、复制及并发编辑都尊重已有属性 | 用两个同名列表项和后置技能栏验证纸面点击、源码光标双向定位。调边距、撤销、复制后回读 YAML，核对纸张、栏目规则、扩展字段；版式 diff 只涉及 frontmatter。覆盖只读母版、过期编辑、重名和失配的栏目。 |
| 4. 一种双栏样式与职位显隐 | 用完整条目归组实现主栏和侧栏。在工作台分配栏位、恢复栏目，原生阅读按原顺序增强 | 源稿含普通段落、技能、嵌入和旧经历块。把后置技能放入侧栏，隐藏荣誉，点击正文再改一行；切回单栏后正文顺序正确，副本仍隐藏荣誉。检查旧主题直接子选择器、普通笔记试排和保护稿。 |
| 5. 原生 PDF 与多页纸张 | 预览、收紧与打印共用 A4／US Letter 的实际尺寸。工作台逐页标记页界与页码，区分手动分页和按块估算的自动分页 | 从工作台和笔记原生菜单导出。用两页中英文样例、手动分页和超过一页的经历逐页核对页码、纸张、首末条、标题与后续正文、边距。查看渲染图片并提取文本与链接，确认隐藏项不在成品，长条目完整，复制顺序可读。核对导出后库级偏好复原。记录 Obsidian 版本和两个入口的差异。 |
| 6. 扩展五类常用结构 | 复用经历头、头部和栏目，补时间轴、头像比例、技能标签与快捷样式。保留作用域 CSS | 在同一篇 Markdown 上切换经典、双栏、时间轴；技能列表可显示为标签，头像可调比例，强调色及栏目／列表间距可还原。比对正文、主题作用域、跨页结果；切换及撤销均保留自定义样式和原文。 |
| 7. 候选版本整体验收 | 更新双语使用说明、示例和维护指南，核对安装包 | 在干净库安装三个发布文件，走完「母版 → 职位副本 → 放置技能 → 隐藏荣誉 → 点击纸面修改 → 两页 PDF」。再从 0.7.0 升级并重载，核对设置、旧主题、最近文件和已确认稿。构建可重复，`npm run check` 通过，实测和未验项目分别记录。 |

### 复验第 4、5 步

1. 英文样例给 Work、Skills 各写一条相同的列表项，再给 Awards 写一个唯一标记。另在 Projects 嵌入一篇自己也有 Awards 标题的笔记。把 Skills 放入侧栏、隐藏外层 Awards，在纸面选中 Skills 的重复项改一个词。磁盘 diff 应仅含版式属性和选中的一行。两个入口导出的 PDF 均须保留嵌入内容，排除外层 Awards 的唯一标记。
2. 中英文样例第一页放姓名、外链和经历，在 `---` 后另起一个带日期的项目，依次放入编号 1–15 的列表项和末尾标记，可得到两页基准。将列表扩展到 65 条复验跨页。工作台由稿件预选纸张；从笔记直接导出时，在 Obsidian 原生对话框选择对应纸张、纵向、100%。
3. 用 `pdfinfo` 核对页数与 MediaBox，用 `pdftotext -layout` 核对每页首末条，用 `pdfinfo -url` 核对外链，再栅格化查看日期对齐和页底。另用默认的 `pdftotext` 检查不保留版式时的阅读顺序。双栏内的日期紧随职位，默认提取应依次得到「Former role → 2019–2022 → Legacy achievement」，且日期只出现一次。

### 复验第 6、7 步

1. 在同一份稿件插入一张库内照片、一个带链接的技能清单和一条旧 HTML 经历。依次切换经典、双栏、时间轴，再从时间轴另存一个 CSS 主题。核对正文，调三种照片比例、位置、强调色和两种间距；依次恢复主题和撤销。在旁边打开普通笔记，检查其标题样式。将带相对照片路径的保护稿复制到其他目录，核对副本仍显示同一张照片。
2. 新建测试库，放入三个安装文件并启用。母版链接一份独立 Markdown 来源。让 Work 和 Skills 各有一条 `Repeat bullet`，将后置的 Skills 移入侧栏并显示为标签，隐藏 Awards。在纸面选中 Skills 的重复项，修改后回读磁盘，只有第二条被改动，母版与来源逐字相同。
3. 在隐藏的 Awards 后放手动分页和 Projects。第一页保留侧栏，第二页只有主栏，两页各含新 Markdown 和旧 HTML 条目。工作台在适应整页和 100% 都显示 `1/2`、`2/2`。两个原生入口导出的 A4 PDF 均有两页；用默认文本提取和保留布局两种方式检查第二页，均依次读出项目、日期、成果。第一页的隐藏标记缺席，作品集链接仍可点击。两份 PDF 在 85 dpi 下逐页像素一致。直接复制双栏全文时仍可见两栏文字穿插，职位与日期在本次样例中相邻。
4. 在第二个测试库先安装 `0.7.0` 标签的三个文件。更改六项设置、保存试排和自定义 CSS，让一个状态为 `ready` 的申请关联已确认稿；最后打开旧 HTML 简历。关闭 Obsidian，只替换三个安装文件并重开，再单独重载插件。核对恢复的工作台标签与最近笔记、两条旧日期、设置与试排记录。在 100% 预览下，旧主题的标题下边框仍为 5 px；已确认稿要求创建副本，写入原件会被拒绝。比对两份旧稿、申请记录及主题文件的 SHA-256。
5. 在新装库打开两份随附示例。中文 A4 使用技能侧栏，英文 Letter 使用经历时间轴，两份各有两段经历、四个技能标签，分别原生导出一页。用独立检出重建后，比对检出、干净库、升级库与 ZIP 中的三个文件。[示例与使用说明](../README.md) · [重建与打包命令](maintenance.md)

本次桌面实测环境为 macOS、Obsidian 1.15.1。清单声明的最低版本为 1.5.0，该版本与其他操作系统留待兼容性复验。页码出现在工作台纸面指引上，PDF 页数和每一页的内容用导出成品核对。
