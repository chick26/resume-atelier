# Resume Atelier v0.8 · 产品体验全面审查与重构方案（复核定稿）

> **适用仓库**：`resume-atelier`（基线：`v0.8.0` 候选版 `1f8e595`）  
> **修订说明**：已吸收 2026-11-26 在 macOS / Obsidian 1.15.1 独立库进行的 5 条桌面实测复核与逐项源码核对意见，修正了头像入口、混合分页告警、跨栈撤销次序、`.deleted/` 恢复保护与 P2 原生 PDF 验收标准。  
> **核心理念**：复杂性由系统承担，不留给用户；体验克制、自解释、零打断、可撤销、防误触。

## 一、产品定位、设计原则与已确认拍板

2026-11-27 起，以[单栏版式验收](#单栏版式)为准。下文双栏相关的条目记录该功能移除前的设计与验收。

### 1.1 产品定位（三层渐进增强）
1. **正文层（100% 原子、线性、无锁定 Markdown）**：只表达最小语义（`# 姓名`、`>` 联系方式、`![avatar](...)`、`## 栏目`、`### 职位 · 公司 | 日期`、标准列表与行内格式）。脱离插件、Git diff、AI 协作均完全可读可改。
2. **声明式版式层（Frontmatter + 渲染期 DOM 归组）**：把双栏、时间轴、标签列表、栏目显隐、纸张与边距解耦到 `resume_style / resume_density / resume_layout / resume_sections`，通过 Obsidian 原生 `MarkdownRenderer` + 原生 `printToPdf` 输出**矢量文字、超链接可用**的原生 PDF。
3. **逃生舱层（原生语法 + Scoped CSS 主题）**：不取代原生渲染，不封死自定义 HTML / Markdown；极客级样式下沉到隔离作用域 CSS 主题编辑器，拒绝通过堆砌 UI 开关把产品做重。

> **产品克制边界**：只接住简历高频的 5 类结构——**经历头分列/时间轴、头部名片+证件照、主栏+侧栏双栏、技能/证书标签网格、单栏目临时显隐**。不做自由画布拖拽、不做技能进度条、不做 `html2canvas` 截图式 PDF。

### 1.2 核心 UX 原则（本次审查与改造准绳）
- 复杂性由系统处理，不留给用户；如果系统可以做出决定，就不要交给用户。
- 如果现在没用，就别显示。
- 如果它能为用户带来好处，那就去做。
- 同样的操作在任何地方都应该以相同的方式生效。
- 按下某个按钮会得到反馈，再次按下可以撤销操作。
- 不要打断用户正在做的事情。
- 简化常用操作的执行，并防止意外触发可能导致数据丢失的操作。
- 界面应该能够自我解释；产品要克制，不要预想太多功能。

### 1.3 已确认的产品收口决策

正文直接编辑 Markdown。经历用三级标题表达，编辑栏只常驻「头像」与保存状态。普通 HTML 由 Obsidian 原生渲染。本轮验收见[正文编辑栏与经历标题](#正文编辑栏与经历标题)。

1. **移除「栏目前间距 / 列表项间距」滑块**：从 UI 移除这两个会覆盖并打断「排版密度」与「收紧至一页」的局部间距滑块（数据层保留对旧笔记已有字段的兼容读取，打开不改写旧稿；主动切换密度、重置微调或收紧时正确接管，撤销可恢复原值）。
2. **砍掉设置页的「自动保存可编辑简历的版式改动」开关**：已识别的可编辑简历一律自动保存 + 全量撤销；仅对尚未启用排版的普通 Markdown 笔记保留一次性的「应用简历排版」确认门。
3. **内置主题收口为 5 套**（经典衬线 / 现代无衬线 / 双栏现代 / 经历时间轴 / 黑白 ATS）：「简洁蓝」退居隐藏兼容主题，旧笔记声明 `resume_style: 简洁蓝` 时静默兼容渲染、不报主题缺失，也不再占用新用户的默认列表。
4. **保留 `.deleted/` 显式手动清理**：`.deleted/` 存放用户自写的主题 CSS，不做按天数或数量的静默删除，保留在设置页「高级选项」内由用户显式恢复或清理，避免不可逆数据丢失。

## 三、目标信息架构与交互设计规范

### 3.1 顶栏与分页告警规则
- **顶栏结构**：左 `[简历选择 ▾]` + 轻徽章 + `[↗ 打开原笔记]`；中 `[缩放 ▾]` + 页数状态 + `[收紧至一页 / 撤销收紧]`；右 `[编辑内容 / 完成编辑 / 创建副本并编辑]` + `[面板开关]` + `[导出 PDF]`。
- **分页三态判定（基于 `starts = measurePageStarts(...)`）**：
  - `hasManual = starts.slice(1).some(s => s.manual)`
  - `hasAuto = starts.slice(1).some(s => !s.manual)`
  - **单页（`starts.length === 1`）**：纸面**不显示** `1/1` 与分页线；顶栏正常显示 `1 页 · xx%`。
  - **纯手动多页（`hasManual && !hasAuto`）**：顶栏**不标红**（中性态），显示 `预计 N 页`；隐藏 `[收紧至一页]`。
  - **纯自动溢出（`!hasManual && hasAuto`）**：顶栏**标红**（`is-overflowing`），显示 `超 X mm · N 页` + `[收紧至一页]`。
  - **手动 + 自动混合多页（`hasManual && hasAuto`）**：顶栏**标红**提醒存在非预期自动跨页（如 `预计 3 页 · 含自动分页`），并在 `aria-label` / tooltip 中写明手动与自动页数；因含手动分页不自动收紧至一页，但保留手动页界。
- **纸面页标自解释（不依赖 hover）**：仅 `starts.length > 1` 时渲染，第 1 页标 `1/N`，后续页直接标 `2/N · 手动分页` / `3/N · 预计分页`（英文 `2/N · Manual` / `3/N · Auto`），同时顶栏状态元素保留完整 `aria-label` 供读屏读取。

### 3.2 头像：双入口无缝协作，不打断写作
- **排版面板（「微调」区）**：
  - **无照片 + 可编辑稿**：只显示一个干净按钮「添加头像」（点击呼出 `PhotoPicker`，插入后自动显示下方样式项）；只读稿无照片时不显示。
  - **已有照片**：显示实际生效值（去掉模糊的「主题默认」占位）——
    - `比例`：`1:1` / `3:4` / `4:5`
    - `圆角`：`1:1` 提供 `圆形 / 小圆角 / 直角`；`3:4` 与 `4:5` 仅提供 `小圆角 / 直角`。*兼容规则：打开已有 `3:4 + round` 旧稿时不静默改写文件；仅当用户主动从 `1:1` 切到 `3:4 / 4:5` 或主动调整圆角时自动降级为 `小圆角`。*
    - `位置`：**仅双栏主题（`mode === "sidebar"`）显示**，选项为 `名片右侧` / `侧栏顶部`。
    - 可编辑稿附轻量 `更换头像` / `移除头像`。
- **编辑内容模式（彻底删除 `setAppearanceInEditor()` DOM 搬运）**：
  - 源码框上方保持干净，不放颜色、间距或版式保存区。
  - 工具栏「头像」按钮与点击纸面头像共用**照片专属轻量 Popover**：
    - 无照片时：点工具栏「头像」直接打开 `PhotoPicker`，选图插入 `![avatar](...)` 后**焦点保持在源码 `<textarea>`**，可继续打字或立即按 `⌘Z` 撤回刚插入的图片；
    - 有照片时：点纸面头像或点工具栏「头像」展开轻量 Popover（仅含：比例、圆角、双栏时的位置、更换头像、移除头像），按 `Esc` 或点击外部立即关闭并返回正文焦点。

### 3.3 右侧「版式」Tab 与「栏目」Tab（统一、克制、防遗忘）
- **「版式」Tab**：
  - 常显主区：`视觉主题`（5 套高辨识度内置主题 + 自定义主题 + 齿轮进设置；`简洁蓝` 保留为隐藏兼容内置主题，旧笔记声明时正常渲染且下拉保留当前项、不报缺失）、`排版密度`（舒适 / 标准 / 紧凑）、`纸张`（紧凑二段按钮 `A4 | US Letter`）。
  - **单一「微调」折叠区**：`强调色`（5–6 个克制专业色点含默认复位 + 自定义取色器，再点当前色点恢复默认）、`头像`（按 3.2 按需显示）、`页边距`（联动 + 四边滑块）、`正文`（字号 / 行距）、`显示边距参考线`，底部统一的 `[重置微调 / 撤销重置]`（未改动时隐藏；按下同时重置几何与外观并弹 Notice，再按还原）。
  - **移除 UI 中的 `sectionGap / listGap` 滑块**，但数据层保留读取旧值：打开旧稿不改写文件；主动切密度、重置微调或成功收紧时清理这两个旧覆盖值；收紧失败时完整回滚保留原值；撤销时还原旧覆盖值。
- **「栏目」Tab 与隐藏防遗忘**：
  - 侧栏（`panel-left`）、标签（`tags`）、隐藏（`eye/eye-off`）3 个按钮补齐 `aria-pressed="true/false"` 与高亮样式，隐藏行整行降透明度并弱化标题，确保视觉与无障碍树均可辨认。
  - `missingSectionRule` 提示行右侧增加 `[清除]` 按钮，一键移除失效键并进入撤销栈（不影响其他栏目规则）。
  - **隐藏栏目全状态提醒**：存在隐藏栏目时，「栏目」Tab 显示 `栏目 · {count} 隐`；当右侧排版面板收起（或当前在编辑模式）时，在顶栏导出按钮旁或面板开关上同时展示轻提示/角标（如 `已隐藏 {count} 栏`，点击可展开定位到「栏目」Tab），防止收起面板状态下误导出缺内容 PDF。

### 3.4 双栏智能默认决策（精确边界）
- 触发条件：**仅当**用户在工作台主动切换到 `sidebar` 结构主题，且当前笔记没有任何 `region: "sidebar"` 规则、且栏目数 ≥ 2 时执行一次：
  - 仅从**唯一、可见**的栏目中匹配常见辅助栏目名（优先技能类：`核心技能 / 专业技能 / 技能 / 技能特长 / 技术栈 / Skills / Core Skills / Technical Skills`；次选辅助类：`专业证书 / 证书 / 荣誉证书 / 语言能力 / 教育背景 / 教育经历 / Certifications / Languages / Education / Awards`）；
  - 若命中：与切换主题合并为同一次 `layout.commit()` 写入 `region: "sidebar"`，弹 Notice 告知用户并支持一键撤销；
  - 若无命中：不强猜，显示一行轻提示引导去「栏目」分配；
  - **尊重用户手动撤回**：一旦用户把栏目手动移回主栏，后续重渲染或微调绝不再次自动放回侧栏；同时兼容被 `---` 手动分页隔开的栏目组。

### 3.5 统一按时间顺序的撤销栈
- 由工作台维护按文件的时间序操作历史（统一协调版式改动与栏目增删/调序正文改动），取消 `recognized && !readOnly` 的限制：
  - 正式简历、普通笔记试排、受保护稿试排**全部支持连续撤销**；
  - 连续执行「拖动栏目 → 隐藏栏目 → 连续撤销」时，**严格按逆序恢复**：第 1 次撤销恢复隐藏栏目的显示，第 2 次撤销恢复正文的栏目顺序（若期间正文在外部变动，跳过过期正文项并安全提示）；
  - 普通笔记在点击「应用简历排版」前始终仅存预览态、不写盘；母版与冻结稿原文件始终逐字不变。

### 3.6 设置页精简与安全保护
- **砍掉**：`autoSaveLayout` 开关（忽略/清理旧 `data.json` 字段，已识别可编辑简历恒定自动保存；保留普通笔记的应用确认门）。
- **保留**：`clearDeletedThemeCache` 显式清理按钮留在「高级选项」折叠区内，不静默删除 `.deleted/` 中用户自写的 CSS。
- **收纳**：「编辑副本保存位置」移入「高级选项」；设置页主题列表优先展示自定义主题，内置主题收纳在可折叠的「从内置主题复制自定义…」区。
- **主题 CSS 防误丢**：`theme-editor.js` 跟踪名称与 CSS 草稿的脏状态；干净草稿一步退出，有改动时点「← 返回排版」或「取消」先要求确认（`确认放弃改动`）并允许留下来继续编辑。
